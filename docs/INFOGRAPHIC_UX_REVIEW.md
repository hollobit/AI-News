# 인포그래픽 인터랙션·이해도 개선 분석

검토일: 2026-09-29. 기준: cccf6c9의 docs/news-architecture.html. 인포그래픽에 대한 분석이며 전체 운영 사이트를 다시 감사한 결과가 아니다. 이번 작업은 제품 코드나 실행 설정을 변경하지 않았다.

## 실제 확인

- 390×844 브라우저에서 첫 순환 단계를 클릭했을 때 설명 패널의 viewport 기준 top은 약 2,020px였다. 문서 전체 높이는 약 2,291px로, 클릭 결과가 시야 밖에 남는다.
- STEP 06 선택 후 새로고침하면 STEP 01로 돌아온다. 현재 선택은 메모리 변수이며 독립 HTML의 URL/저장소로 복원하지 않는다. 대화창용 window.openai 상태는 독립 브라우저에서 작동하지 않는다.
- STEP 04에 키보드 포커스를 둔 뒤 viewport를 1080→1040으로 바꾸면 activeElement가 BODY로 바뀐다. ResizeObserver가 전체 버튼 DOM을 교체한다.
- 순환 보기의 선택은 카드 윤곽과 하단 설명만 바꾼다. 연결선·선행/후속 단계의 강조는 없고, 다른 세 보기의 노드는 탐색할 수 없는 SVG다.
- 순환도는 병행 작업이라는 설명을 제공하지만 8단계 원형 배치는 모든 작업이 매번 순차 실행되는 것으로 읽힐 가능성이 있다. 이는 사용자 실험으로 확인된 결과가 아니라 정보 구조에 대한 전문가 판단이다.

## 표현과 접근성

- 중앙의 큰 영문 장식 대신 선택 단계의 이름, 처리 조건, 입력/출력 설명을 배치한다. 장식 면적을 이해에 필요한 정보에 사용한다.
- 색상은 자료/실행/검토 등의 의미를 안정적으로 유지하고 텍스트와 선 모양을 병행한다. 선택하지 않은 필수 글자를 과도하게 흐리게 하지 않는다.
- 단계 선택·경로 변경 시 짧은 전환을 사용한다. 상시 회전·흐르는 입자·자동 화면 이동은 추가하지 않는다. 자동 설명 재생에는 정지 기능을 제공한다.
- 조작은 키보드로 가능해야 하며 포커스를 보존한다. 모바일은 44px 수준의 실용적 터치 영역을 목표로 하고, 상세 패널이 포커스된 조작을 가리지 않도록 한다.
- 가상 시나리오, 구조 설명, 실제 상태 조회를 명시적으로 구분한다. 조회 오류를 대기 0건이나 정상 상태로 표시하지 않는다.

참고: W3C [WCAG 2.2 변경 사항](https://www.w3.org/WAI/standards-guidelines/wcag/new-in-22/), [Pause, Stop, Hide](https://www.w3.org/WAI/WCAG22/Understanding/pause-stop-hide). 전체 WCAG 적합성 감사를 수행했다는 의미는 아니다.

## 구현 및 검증 순서

1. 선택 상세 위치·포커스 보존·URL 복원부터 수정한다.
2. 단계 ID를 공유하는 데이터 모델로 네 보기를 연결하고 경로의 병행/조건을 표현한다.
3. 단계별 설명 재생과 대표 예외 시나리오를 추가한다.
4. 필요할 때만 로컬 운영 상태 읽기 연결을 별도 범위로 구현한다.

기존 화면 크기·테마·넘침 검사는 유지한다. 선택 결과가 화면에 보이는지, 키보드 포커스와 URL 복원, 빠른 전환과 리사이즈, 동작 감소 환경, 가상 시나리오가 서버에 변경 요청을 보내지 않는지를 추가 검사한다. 이후 사용자가 ‘새 기사의 다음 단계’, ‘지연 원인’, ‘어떤 결과가 공개되는지’를 설명할 수 있는지 과제 기반으로 확인한다. 성공률·소요 시간은 측정 후 기록하며 임의 개선 수치를 주장하지 않는다.


## 구현 완료 — 2026-09-29

- 모바일 선택 카드 아래 상세, 데스크톱 중앙 입력·처리·출력과 펼침 설명을 적용했다. 단계 버튼을 재사용하고 리사이즈는 연결선만 다시 계산한다. SVG 상세 보기의 키보드 포커스도 복원한다.
- 보기·단계·시나리오를 URL hash에 저장한다. 새로고침, 뒤로/앞으로, 잘못된 상태값의 기본 복원을 지원한다.
- 5개 가상 시나리오별 데이터 경로·건너뛰기·대기 조건을 표시한다. 병행 감독과 다음 수신 연결은 점선으로 구분하고, 독립 실행과 조건별 분석을 명시한다.
- 이전/다음 및 명시적으로 시작·정지하는 설명 재생을 구현했다. 각 예시 경로의 끝이나 대기 지점에서 정지하며 백그라운드 탭에서는 멈춘다. 동작 감소 환경을 지원한다.
- 공통 단계 ID로 4개 보기를 연결했다. 상세 구조의 노드도 클릭·Enter·Space로 선택 가능하며 입력/출력 요약과 관련 연결선을 강조한다.
- 명시 클릭으로만 이 컴퓨터의 로컬 운영·뉴스 화면을 연다. 실시간 상태 API 연결은 이번 설명 도구에 추가하지 않았다. 시나리오는 실제 작업을 실행하지 않는다.
- 4개 보기×5개 너비×2개 테마의 레이아웃 검증과 상호작용 회귀 테스트를 통과했다. 포커스·설명 가시성·URL·5개 시나리오·재생 정지·오프라인 요청 0 검증을 CI에 포함한다. 사용자 과제 기반 이해도 실험은 아직 수행하지 않았다.
